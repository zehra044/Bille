# Bille

# User Flow

Version: 0.1

---

# Overview

This document describes how users navigate through Bille to complete common tasks.

The application is designed to minimize the number of steps required to manage customer accounts.

---

# Main Navigation

Dashboard
├── Customers
├── Reports
├── Trash
└── Settings

---

# Flow 1 - Create Customer

Dashboard
    ↓
Customers
    ↓
Tap "Add Customer"
    ↓
Enter Customer Information
    ↓
Save
    ↓
Customer Account

---

# Flow 2 - Add Charge

Dashboard
    ↓
Customers
    ↓
Select Customer
    ↓
Customer Account
    ↓
Tap "Add Charge"
    ↓
Enter Charge Details
    ↓
Save
    ↓
Customer Account Updated

# User Journey

Most users will follow this workflow:

Open App
    ↓
Dashboard
    ↓
Customers
    ↓
Select Customer
    ↓
Customer Account
    ↓
Choose Action
        ├── Add Charge
        ├── Record Payment
        ├── View Transactions
        ├── Share Statement
        └── Edit Customer
